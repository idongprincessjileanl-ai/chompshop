Database Administrators

Designs the ERD, normalizes tables, writes complex SQL (views, stored procedures, triggers), and manages schema generation for Skyline Market, an e-commerce platform with demand forecasting.

Responsibilities

1. Design the ERD

Model products, customers, orders and forecasts with clear one-to-many relationships.

2. Normalize tables

Bring every table to 3NF to remove redundancy and update anomalies.

3. Write complex SQL

Views, stored procedures and triggers that enforce rules inside the database.

4. Manage schema generation

One repeatable schema.sql that builds the database and seed data.

Normalization

1NF

Atomic values only. Order lines live in order_items, not as a list inside orders.

2NF

No partial dependencies. Product details depend on product_id, not on the order line.

3NF

No transitive dependencies. Category names sit in categories, not repeated in products.

Advanced SQL objects

View

v_daily_sales aggregates units and revenue per product per day.

Stored procedure

sp_generate_forecast writes a 7-day moving-average demand forecast.

Triggers

Block overselling, deduct stock, and audit every price change.

CREATE TRIGGER trg_order_items_before_insert
BEFORE INSERT ON order_items FOR EACH ROW
BEGIN
  DECLARE v_stock INT; DECLARE v_price DECIMAL(10,2);
  SELECT stock, price INTO v_stock, v_price
    FROM products WHERE product_id = NEW.product_id;
  IF v_stock < NEW.quantity THEN
    SIGNAL SQLSTATE '45000' SET MESSAGE_TEXT = 'Insufficient stock';
  END IF;
  IF NEW.unit_price = 0 THEN SET NEW.unit_price = v_price; END IF;
END
